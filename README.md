# 学术成果智能归集与认领系统

面向高校科研管理的课程设计项目：从论文、专利增量归集，到作者与发明人消歧、教师认领、审核申诉和多口径统计。

**项目状态：设计与评审中。** 当前仓库仅有设计材料，尚未提供可运行系统、测试结果、CI/CD 或部署包。

## 设计材料

- [立项评审](docs/design/00-立项评审.md)：范围、同类产品、评分追踪及风险。
- [需求规格](docs/design/01-需求规格.md)：角色、业务目标与验收条件。
- [系统架构草案](docs/design/02-系统架构.md)：增量归集、匹配、审核、统计与持续交付设计，待技术评审。

首版使用独立 HTTP 模拟源和可复现的合成数据，不需要学校名册、第三方 API 密钥或正式考核口径。模拟数据上的评测结果不代表真实高校环境中的准确率。

仓库不收录课程站内容、私下沟通截图、真实人员名册、认领证据或访问凭据。开源许可证尚未选定。
