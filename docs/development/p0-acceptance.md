# P0 演示验收清单 · 2026-11-25

验收目标：验证合成论文、专利从自动归集到人工审批、可解释统计的可重复链路。这不是安装到真实学校环境，也不是最终课程提交包。

| 追踪项 | 必验行为 | 独立取证入口 |
|---|---|---|
| ING-01 / ING-02 | 两批经 HTTP 自动拉取；更新、重复、授权合并；失败页水位不越界，重跑幂等，过期任务被阻挡 | `tests/test_ingestion.py`、Compose 同步流水、临时数据卷 |
| MAT-01 / MAT-02 | 同名场景给解释或弃权；不得自动认领；固定合成标签集输出可复现的基线及多证据指标 | `tests/test_matching_*.py`、`python -m apps.matching.evaluate` |
| CLM-01 / CLM-02、BIZ-01～03 | 忽略不阻挡主动认领、权限和 CSRF、不能并发重复归属、原审不得复核、决策留痕 | `tests/test_claims_workflow.py`、独立端到端操作 |
| RPT-01 / RPT-02、BIZ-04～06 | 口径切换、历史任职、校级/院系去重、明细及 CSV 一致、旧快照不被修订 | `tests/test_reports.py`、Compose 端到端脚本 |
| RPT-01 年度趋势 | 同口径跨年计数，包含缺年零值、授权过滤、按类型拆分与保留筛选的年度下钻；冻结页面不展示实时趋势 | `tests/test_acceptance_trend.py`、实时看板 |
| OPS-01 | 锁文件构建、真实 PostgreSQL 迁移、全新卷 Compose、前端可访问、部署 ZIP 校验和 GitHub PR 门禁 | `scripts/ci/compose_smoke.py`、`scripts/ci/package_demo.py`、PR Checks |

## 分工与证据边界

实现负责人提交生产代码和文档；一名不参与生产代码实现的子代理进行独立测试与复验。在隔离的测试数据库运行，不污染现有本地演示。相关自动化测试随代码进入版本控制，以便 CI 重跑。

- 测试通过须绑定到候选提交；浏览器操作与 HTTP 脚本分别记录，不能互相冒充。
- 版本发布流程与真实发布分开。此阶段不合并 PR、不创建发布标签、不向外部署；可验收部署 ZIP 构建与校验，不据此宣称 GHCR 已发布。
- 课程课件映射、个人复盘签认、最终答题摘要和课程 ZIP 属于后续提交整理，不计入本阶段实现验收。
