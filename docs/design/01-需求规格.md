# 学术成果智能归集与认领系统 · 需求规格 v0.3

状态：已完成一轮业务评审；拟采用规则及验收场景见[业务评审](03-业务评审.md)。尚未实现或验收。 | 2026-11-24

## 1. 问题与范围

科研管理人员要获得可解释、可核查的统计，教师要减少重复填报，同时不因同名、异名、调动或共同署名被错认。系统自动发现**候选**成果，不代替教师和审核人做归属决定；不能证明“高校全量无漏报”或代替正式评估。

首版面向单校、多院系。支持期刊/会议论文和专利；支持定时拉取、数据库回放、作者/发明人匹配、认领与申诉、政策版本化统计、趋势与明细。默认由独立 HTTP 模拟源提供固定种子的论文、专利批次。自动归集须经过真正的请求、分页与入库；仅初始化角色与组织的种子脚本不负责成果入库。界面明确标记模拟数据，不承诺接入具体厂商或真实学校。非目标：全文仓储、商业数据库/校内系统对接、跨国专利族合并、正式考核结论、多租户、通用低代码流程和统计平台。

## 2. 用户与权限

| 角色 | 任务 | 约束 |
|---|---|---|
| 教师 | 查看自己的待认领、忽略误推、按 DOI/专利号发起认领、补充证据、跟踪与申诉 | 不替他人认领，不改来源元数据，不看他人的证据 |
| 院系审核员 | 审核管辖院系的认领并填写理由 | 不审核自己的认领，不越权读取、审核或导出 |
| 校级复核员 | 处理申诉、纠错和待分派，按授权查看校级统计；必要时补位初审 | 不得审核自己的认领，不得复核自己初审的案件 |
| 系统管理员 | 管理人员、院系任职和权限、数据源、作业和策略版本 | 运维身份不默认取得审核或证据查看权 |

审核管辖锁定为提交时教师的主责院系；无主责院系或无合格院系审核人时转校级待分派。调院不自动转派存量案件；调整要留原因。管辖院系不是统计归属，后者按成果事件日历史任职确定。匿名访客不访问管理业务。工作台只展示当前账号可用的入口；教师直接访问院系或校级统计、趋势、导出仍须返回 403，并提示如何返回或切换账号。隐藏导航不替代服务端授权。首版只接收限定长度的文字证据和标识符，不收附件，不由服务端访问用户输入的链接。

## 3. 需求与验收证据

| ID | P0 验收场景（待实现） | 证据 |
|---|---|---|
| ING-01 | 两类外部模拟数据流按固定范围自动增量同步；第二批同时含新增、更新和重复；同一批再跑无新增重复成果、署名或业务动作 | 两类 HTTP 请求日志；固定发布批次和重复拉取断言；作业界面 |
| ING-02 | 注入一页超时、限流或处理失败；可重跑，未处理完的窗口不推进同步水位；错误有分类、计数和重放入口 | 连接器契约、故障恢复集成测试 |
| MAT-01 | 同名异院系、拼音/别名、缺失机构、外校人员不可可靠识别时给出证据或弃权；评分版本可追溯；不直接生效 | 候选详情、错误案例、特征解释测试 |
| MAT-02 | 在冻结的合成测试集上对比“姓名基线”和多证据模型，报告评估样本、阈值、Precision/Recall/F1、Top-1、Recall@K、覆盖率、失败案例，论文和专利分报 | 一条可复现命令、版本化数据清单、报告；未跑不写分数 |
| CLM-01 | 教师甲乙可各认同一成果的不同署名位；同一署名位不可能并发核准给两个人；重复提交、越权、本人审核被拦截；无合格院系审核人则转校级待分派 | 角色 E2E、PostgreSQL 并发/约束测试 |
| CLM-02 | 一次认领被驳回，教师一次申诉，独立复核改判；不允许绕过驳回另开申请，或在复核时静默覆盖已有归属；每步有操作者/理由/时间；忽略推荐不算驳回 | E2E、审计事件、统计前后对照 |
| RPT-01 | 切换统计口径得到可人工核对的不同结果；指标可点到授权明细；图表和 CSV 对同一结果集一致；1–10 年趋势保留口径和授权范围，缺年显示 0，可下钻至该年明细 | 黄金数据集、确定性测试、看板 |
| RPT-02 | 已发布快照保存口径版本及所用数据；审批改判、上游更新和新口径不改变旧快照 | 快照重开及哈希/行对比测试 |
| OPS-01 | 干净环境可按说明启动一个带合成种子的演示；测试归集不依赖外网数据源或密钥；版本化产物可验证 | Compose 冒烟、CI 和 Release 记录 |

模拟源可通过受控批次推进、限流/错误注入和回放进行验收；部署环境需明确源类型、采集范围与数据版本。评分阈值只在验证集调参，性能门槛在确定演示环境后定义。P1：真实公共连接器、授权机构名录或 SSO、更多统计政策、批量操作及非高风险通知。

## 4. 统计政策（项目自定义示例，非学校正式口径）

两种策略均只纳入有效核准关系：

| 规则 | 成果概览 v1 | 学院考核示例 v1 |
|---|---|---|
| 论文 | 首次正式公开发表年度，院系内每成果一次 | 同一日期规则，论文只计署名第一位所在院系且该署名已核准 |
| 专利 | 首次公开或授权中更早的可证日期，同一管辖区申请只计一次 | 仅已发生授权且有授权日期的专利，按授权年份；第一发明人须已核准 |
| 归属 | 所选统计事件日期的历史任职；同一成果可归属多个学院 | 同一历史归属规则，但只取首位贡献者；不把申请人当作发明人 |
| 缺失 | 必要的完整日期、任职或首位缺失时不猜测，给排除原因 | 同左 |

首位是来源中的顺序，不推断共同一作/通讯作者；若来源不提供可靠序位，该严格口径不计。任职重叠首版仅统计明确标为主归属的部门，否则转待核对。校级按成果 ID 独立去重，不等于院系分项相加。专利公开、授权是同一国内/地区申请的事件，不自动合并不同辖区申请。审批时间不改变成果统计年度。晚核准与撤销归属在新统计中生效，不重写已发布快照；必要时发布更正快照。
